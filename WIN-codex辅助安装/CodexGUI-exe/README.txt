Codex 助手  Windows 独立 exe  打包说明
====================================================

这个文件夹用于：把 Python 图形版 Codex 助手打包成一个
【双击即用、自包含】的 Codex助手.exe ——
不依赖 Python、.NET，也不依赖任何运行库。

----------------------------------------------------
① 怎么得到 exe？
----------------------------------------------------
1) 先把整个 "CodexGUI-exe" 文件夹 原样拷贝到你的
   Windows 电脑上（建议放桌面，路径不要有中文和空格，
   更不要放在 \\Mac\Home 这类网络共享盘里）。

2) 双击里面的 build-exe.bat，脚本会自动：
     · 找 Python（没有会提示你先装一次 Python）
     · 联网安装 PyInstaller
     · 打包生成  Codex助手.exe  （约 1~3 分钟）
   脚本为避开中文路径问题，会在干净的本地临时目录里
   打包，完成后自动把 exe 复制回本文件夹。

3) 打包只需做这一次。之后那个 Codex助手.exe 拷到任何
   Windows 电脑都能直接用。

----------------------------------------------------
② 一次性要求：需要装 Python 才能打包
----------------------------------------------------
只有第①步需要 Python（且只需要一次）。
如果你机器还没有 Python：
   · 打开 https://www.python.org/downloads/ 下载 3.10+；
   · 安装时务必勾选：
         □ Add python.exe to PATH
         □ tcl/tk (Tkinter) 图形支持
   · 装完重新双击 build-exe.bat 即可。

若已有 Python 但打包时提示缺 tkinter，用官网完整安装包
重装一次并勾选 tcl/tk 即可。

----------------------------------------------------
③ 运行
----------------------------------------------------
直接双击  Codex助手.exe ：
   · 选择模型 → 填 API Key → 应用并启动 → 开聊
   · 支持“汇聚模式”（多厂商同用）
   · 首次运行会把内置的 codex-relay.exe / relay-gateway.exe
     自动释放到  C:\Users\你的用户名\.codex\
   · 状态 / 结果用直观弹窗反馈，日志写在窗口下方

注意：杀毒软件可能对“自解压单文件 exe”报未知，属正常
误报。若被杀请选择“允许/保留”，或运行前临时关闭实时防护。

----------------------------------------------------
④ 本文件夹内容
----------------------------------------------------
   codex-gui.py        —— 图形程序源码（可单独用 python 跑）
   resources\          —— 内置 relay / gateway 程序（打包进 exe）
   app.ico             —— exe 图标
   build-exe.bat       —— 一键打包脚本
